# 「プリン」は絶対食べるなよ！

妹が帰ってくるまでに、冷蔵庫のデザートを見分けて盗み食いする、**デザート鑑定 × 証拠隠滅ゲーム**です。

プリン、パンナコッタ、ババロア、ムース、ブランマンジェ、ミルクプリン、牛乳寒天、杏仁豆腐など、見た目のよく似たデザートが冷蔵庫に並んでいます。

妹が「食べるな」と指定したデザートを避けながら、制限時間内に空腹を満たしてください。

## ゲームの特徴

### 見た目だけでは分からないデザートを鑑定

デザートは、色やトッピングだけでは判別できません。

- 観察する
- においを嗅ぐ
- 揺らす
- 押す
- すくう
- 味見する
- 完食する

といった行動で情報を集め、ゲーム内の図鑑と照らし合わせて正体を推理します。

弱い鑑定は安全ですが、得られる情報は限定的です。強い鑑定ほど正体へ近づける一方、デザートに傷や欠損を残します。

### 食べれば分かる。でも、食べたものは戻らない

味見や完食は、正体を知るための強力な手段です。

同時に、妹が残すよう指定したデザートを食べてしまう危険もあります。

食べることは、

- 空腹を満たす
- 正体を知る
- 現物を減らす、または消滅させる

という三つの結果を同時に発生させます。

### 間違えたら、帰宅までに証拠を隠滅

指定されたデザートを傷つけたり食べたりしても、即ゲームオーバーではありません。

冷蔵庫の材料や、ほかのデザートを使って修復・偽装・再製造を試みられます。

- ホイップやソースで傷を隠す
- 別のデザートから一部を移植する
- 容器を入れ替える
- 材料を組み合わせて作り直す

修復の結果、見た目や中身が変わり、別のデザートに近づくこともあります。

### 空腹、時間、原形を管理

何も食べなければ安全ですが、空腹を満たせないためクリアできません。

すべての鑑定・食事・修復・調理には時間がかかります。妹が帰宅するまでに、必要なデザートと個数を残し、証拠を片付ける必要があります。

## 基本的な遊び方

1. 妹のメモを確認します。
2. 冷蔵庫内のデザートを選びます。
3. 図鑑と鑑定結果から、安全に食べられるものを推理します。
4. デザートを食べて空腹を満たします。
5. 指定対象を傷つけた場合は、帰宅までに修復・偽装・再製造します。
6. 妹の帰宅時に条件を満たしていればクリアです。

## デザート図鑑

本作では、現実のレシピや呼称に幅があることを前提に、ゲーム内図鑑で独自の判定基準を示しています。

図鑑には、各デザートの一般的な特徴が記載されています。

- 主な材料
- 固め方
- 泡立て工程の有無
- 香り
- 硬さや弾力
- 断面や気泡
- 似ているデザートとの違い

図鑑は冷蔵庫内の個体の正解を直接示すものではありません。鑑定で得た情報と照合して判断してください。

## ローカルでの起動

ES Modulesやブラウザのセキュリティ制限に対応するため、ファイルを直接開かず、ローカルサーバー経由で起動してください。

リポジトリのルートで次を実行します。

```bash
node server.js
```

表示されたローカルURLをブラウザで開いてください。

## 注意事項

- 本作はゲームです。
- ゲーム内のデザート分類は、遊びやすさと判別可能性を考慮した独自基準を含みます。
- 現実の料理名、材料、製法には地域差、時代差、商品差、作り手による違いがあります。
- ゲーム内の図鑑は、現実の製菓における唯一の正解を示すものではありません。
- 食品の安全性、アレルギー、調理方法などを判断する資料として使用しないでください。
